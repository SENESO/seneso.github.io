# Eslam Ashraf Antar — profile site

Personal profile and project index of Eslam Ashraf Antar, backend developer
(C# / .NET), Cairo. Static site: plain HTML/CSS/JS, no build step.

All statistics on the page (lines of code per language, per-project figures,
commit activity) are generated from the GitHub API and a per-language line
count of every repository by `scripts/update_stats.py`, refreshed daily by
the `update-stats` GitHub Actions workflow. See `BUILD-NOTES.md` for the
full method, data sources and launch checklist.
